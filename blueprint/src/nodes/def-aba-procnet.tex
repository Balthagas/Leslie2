\begin{definition}[The program of one process]
  \label{def:aba-procnet}
  \lean{PLTS.ABA.GBCA.ProcNodeN}\lean{PLTS.ABA.CoreNodeN}\lean{PLTS.ABA.Net.ABANodeN}\lean{PLTS.ABA.Net.NetEvt}\lean{PLTS.ABA.Net.NLab}\lean{PLTS.ABA.Net.netEvtLabels}\lean{PLTS.ABA.Net.ABAProcStepN}\lean{PLTS.ABA.Net.ABAProcN}\leanok
  \uses{def:aba-labels, def:aba-gbca-vocab, def:aba-core-vocab, def:relabel, def:syncproduct}
  The state of process $j$ is
  \[
    \mathrm{ABANodeN}(n) \;=\;
      \mathrm{CoreNodeN}(n) \times (\mathbb{N} \to \mathrm{ProcNodeN}(n)),
  \]
  its round-loop node --- the control record of Definition~\ref{def:aba-core-vocab} together with the DECIDED receipt rows $decIn(k)$ --- and one stage node per round, the stage record of Definition~\ref{def:aba-gbca-vocab} together with the inbox rows $inbox(k)$.
  There is no outbox, no copy of the corrupted set and no corruption flag, so every guard of the automaton $\mathrm{ABAProcN}(P,j)$ reads $j$'s own node.
  It runs over the extended alphabet $\mathrm{NLab}(n) = \mathrm{Lab}(n) \oplus \mathrm{NetEvt}(n)$, where $\mathrm{NetEvt}$ names the rendezvous the shared alphabet cannot: the stage multicast $\mathrm{gsnd}(r,j,m)$ and the stage delivery $\mathrm{gdlv}(r,i,j,m)$; the DECIDED relay $\mathrm{dsnd}(j,b)$ and the DECIDED delivery $\mathrm{ddlv}(i,j,b)$; the fused coin return $\mathrm{retWPub}(r,id,c,b)$, which carries beside the coin the payload to be published (D10); the graded-agreement call $\mathrm{gcallLoop}(r,id,b)$ against an already-opened stage record; and the five Byzantine drives $\mathrm{byzCallG}$, $\mathrm{byzCallGLoop}$, $\mathrm{byzRetG}$, $\mathrm{byzCallW}$ and $\mathrm{byzRetW}$ (D11).
  The set $\mathrm{netEvtLabels}(n)$ of these labels is what the composition hides, the silent label of $\mathrm{NLab}(n)$ being that of $\mathrm{Lab}(n)$.
  Every transition is Dirac, no row fires on $\tau$, and every label of either alphabet has a row of process $j$ --- the participant's, or an idle self-loop --- so full synchronisation lets a label's owner move while every other program stands.
  Full rule table: \leandecl{PLTS.ABA.Net.ABAProcN}.
\end{definition}
