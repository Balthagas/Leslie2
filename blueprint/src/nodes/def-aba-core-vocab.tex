\begin{definition}[The round-loop control record]
  \label{def:aba-core-vocab}
  \lean{PLTS.ABA.ProcCore}\leanok
  The control state of one process in the round loop is the record $\mathrm{ProcCore}$: its external input bit, its estimate, whose unset value is the algorithm's $\bot$ awaiting the coin, its round counter, counted from $0$ (D9), its handshake phase, one of $\mathrm{idle}$, $\mathrm{toCallG}$, $\mathrm{awaitG}$, $\mathrm{toCallW}$ and $\mathrm{awaitW}$, the graded outcome of the current round's stage, and a returned flag.
  The round loop's one message is $\langle\mathrm{DECIDED},b\rangle$, a bare bit, so a pool of such messages is a set of bits.
  No field of the record names another process.
  Full record: \leandecl{PLTS.ABA.ProcCore}.
\end{definition}
