\begin{definition}[The GBCA implementation instance]
  \label{def:aba-gbca-impl}
  \lean{PLTS.ABA.GBCA.implInst}\leanok
  \uses{def:aba-labels, def:aba-params, def:aba-gbca-vocab}
  The graded-agreement layer regrouped as one per-round PLTS over the whole system state, the analysis form of \algoref{alg:gbca-impl}{the GBCA implementation}, which is ABDY22's Algorithm~6 (D18).
  Each process runs a five-stage exchange over the message ladder of Definition~\ref{def:aba-gbca-vocab}: it multicasts $\langle\mathrm{INPUT},b\rangle$ on a call and relays it on $f{+}1$ receipts, and each higher level is multicast into its own write-once slot under an $n{-}f$ quorum at the level below and prior participation (D8).
  A process returns grade $A\,b$, $B\,b$ or $C$ by the three wait-until cases of the last block, each reading the receipts its own case names, and the network is set-based and authenticated (D5): each sender owns one idempotent message set, the adversary schedules delivery, and a corrupted sender may inject an arbitrary message.
  The state is the protocol's own data, so the specification's $dead$ and $grade$ appear nowhere in it.
  Full rule table: \leandecl{PLTS.ABA.GBCA.implInst}.
\end{definition}
