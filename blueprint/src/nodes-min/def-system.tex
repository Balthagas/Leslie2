\begin{definition}[Probabilistic labelled transition system]
  \label{def:system}
  \lean{PLTS.System}\leanok
  A PLTS is an initial state together with a step relation carrying a state and a label to a distribution over successor states, and it is the single model every system of this development is written in: \leandecl{PLTS.System}.
\end{definition}
